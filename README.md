## 📖 О проекте

Эта база знаний создана для того, чтобы любой человек мог за 5–15 минут понять любую тему об искусственном интеллекте, начиная с «что такое ИИ» и заканчивая «как работают эмбеддинги и агенты».

### Особенности

- **4 уровня сложности** — от абсолютных новичков до разработчиков
- **Понятный язык** — сложность объяснений зависит от уровня темы
- **Практические примеры** — в каждой карточке есть примеры из жизни
- **Пошаговое обучение** — можно начать с нуля и дойти до профессионального уровня

## 🎯 Уровни сложности

| Уровень | Для кого | Примеры тем |
|---------|----------|-------------|
| **0** | Никогда не пользовался ChatGPT | Что такое ИИ, как начать с ChatGPT |
| **1** | Уже попробовал ChatGPT 1–2 раза | Основы промптинга, что такое модель |
| **2** | Хочет больше приёмов и инструментов | Токены, RAG, агенты, продвинутый промптинг |
| **3** | Готов кодить или платить | Эмбеддинги, векторные базы, fine-tuning, LoRA |

## 🛠️ Как использовать

1. **Начните с уровня 0**, если никогда не пользовались ChatGPT
2. **Переходите к следующему уровню**, когда чувствуете, что готовы
3. **Используйте таблицы в [index.md](./index.md)** для навигации — каждая строка кликабельна

## 🚀 Развёртывание на GitHub Pages

Этот проект настроен для автоматического деплоя на GitHub Pages через VuePress.

### Быстрый старт

1. **Установите зависимости**:
   ```bash
   npm install
   ```

2. **Запустите локальный сервер**:
   ```bash
   npm run docs:dev
   ```

3. **Соберите для продакшена**:
   ```bash
   npm run docs:build
   ```

### Настройка GitHub Pages

Подробная инструкция в файле [DEPLOY.md](./DEPLOY.md)

**Кратко**:
- Создайте репозиторий на GitHub
- Запушьте код в ветку `main`
- Включите GitHub Actions в настройках репозитория
- Настройте GitHub Pages (Settings → Pages → Source: Deploy from a branch → gh-pages → / (root))
- После первого пуша сайт автоматически задеплоится

**Важно**: Если ваш репозиторий называется не `aikb`, измените `base` в `.vuepress/config.js`
